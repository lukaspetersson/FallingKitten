# Falling Kitten

Falling Kitten is a small offline Android reflex game. Rotate each falling kitten so it lands on its feet, then try to beat the local high score.

- [Get Falling Kitten on Google Play](https://play.google.com/store/apps/details?id=com.lukas.android.fallingkitten)
- [How to play](https://lukaspetersson.com/lp-apps/falling-kitten-how-to-play.html)
- [Privacy policy](https://lukaspetersson.com/lp-apps/falling-kitten-privacy.html)
- [Support](https://lukaspetersson.com/lp-apps/falling-kitten-support.html)

## Build

This repository contains the Android app. Use the checked-in Gradle wrapper:

```bash
bash ./gradlew test
bash ./gradlew assembleDebug
```

A local build is not evidence of the version currently published on Google Play.
